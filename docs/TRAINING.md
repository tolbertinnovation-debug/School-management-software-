# Training Materials

Designed for a **half-day, phones-in-hand workshop** per school, run on the demo
database (`npm run seed`) so mistakes cost nothing. Print the quick-start cards
on one page each and laminate them for the staff room.

---

## Quick-start card — TEACHER (print me)

```
MORNING ROLL CALL (30 seconds)
  ✅ Roll call → your class → "Mark all present"
  → tap A on absentees → Save.  Parents get SMS by themselves.

ENTER SCORES
  📝 Grades → class + semester → tap the assessment
  → type scores → Save.  (New quiz? "New assessment" first.)

NO NETWORK?  Keep going. "Saved offline ✓" = safe.
  It uploads alone when network returns. Never re-enter.

FORGOT PASSWORD?  Ask the principal (Settings → Users → reset).
```

## Quick-start card — BURSAR (print me)

```
TAKE A PAYMENT
  💰 Fees → Record payment → student → amount → method
  MoMo/Orange? → type the TRANSACTION ID from the SMS
  → Save → print receipt (parent also gets SMS receipt).

BEFORE DUE DATE   Fees → "SMS reminder to all"
EVERY FRIDAY      tick payments against momo/bank statement → Reconcile
EVERY EXPENSE     📉 Expenses → Record — same day, keep the voucher
```

## Quick-start card — PRINCIPAL (print me)

```
DAILY    Confirm roll calls · staff attendance · approve leaves
TERMLY   Generate invoices → teachers enter scores →
         Generate report cards → review → PUBLISH (sends SMS)
MONTHLY  Payroll drafts → mark paid · check Reports dashboard
WEEKLY   Settings → Backup now → copy newest file to USB, keep off-site
MINISTRY Reports → EMIS CSV downloads
```

## Workshop agenda (4 hours)

| Time | Session | Hands-on exercise |
|---|---|---|
| 0:00 | Why this exists; offline demo (airplane mode!) | Install PWA on every phone |
| 0:30 | Teachers: roll call | Everyone marks the demo class, one phone in airplane mode, watch it sync |
| 1:00 | Teachers: assessments & scores | Create a quiz, enter 5 scores, view computed grades |
| 1:45 | *Break* | |
| 2:00 | Bursar + principal: fees | Record a cash and a momo payment, print a receipt |
| 2:30 | Principal: report cards | Generate → publish → check the parent portal on another phone |
| 3:00 | Parents' flow | Each trainee logs in as a parent (phone+PIN), reads the report card |
| 3:30 | Safety: backups, passwords, audit log | Take a backup to USB together |

**Trainer's golden rule:** every trainee performs every action on their own
phone. Nobody learns by watching.

## Video script outlines (record on any phone, 2-4 min each, English)

1. **"Install the app"** — open browser → address → Add to Home screen → login
   screens for staff vs parent. Close-ups of the two login tabs.
2. **"Roll call in 30 seconds"** — real classroom, teacher walks the aisle
   tapping A on absentees; cut to the parent's phone receiving the SMS.
3. **"Taking a school fee payment"** — parent pays with Orange Money at the
   office; bursar types the transaction ID; receipt prints; parent's SMS.
4. **"Report card day"** — teacher finishes scores → principal publishes →
   parent opens the card at home → printing a copy at school.
5. **"When the lights go out"** — phone in airplane mode doing roll call and a
   payment; network returns; the 📶 badge counts down to zero. Message:
   *nothing is ever lost.*
6. **"Protect the school's data"** — weekly USB backup ritual; why every staff
   member has their own password; the audit log.

Keep videos downloadable (MP4 ≤ 25MB) so schools can share them by Bluetooth /
Xender — do not assume YouTube access.

# Teacher Manual

Everything you do daily takes under a minute on your phone. Install the app:
open the school address in Chrome → menu → **Add to Home screen**.

## Sign in

Username + password from the principal. Change the password in ⚙️ Settings.
If it says *offline*, keep working — your entries upload automatically later.

## 1. Morning roll call (≈30 seconds)

1. ✅ **Roll call** → pick your class → today's date is already set.
2. Tap **Mark all present**, then tap **A** next to anyone absent
   (**L** = late, **E** = excused).
3. **Save roll call.** Parents of absent children get an SMS automatically.

Works with no network — it says "saved offline" and uploads later. Re-saving
the same day corrects earlier marks, it never duplicates.

## 2. Entering grades

1. 📝 **Grades** → pick class + semester.
2. *New assessment* → choose type (quiz / test / assignment / project count as
   **CA**; *Semester exam* is the exam), title and max score.
3. Tap the assessment → type each student's score → **Save scores**.
   Scores above the max are rejected — check the red count in the message.
4. *Computed grades* shows the live CA/exam/final/letter for your class.
   Final = CA average × 40% + exam × 60% (your school may configure this).

## 3. Report cards

Generate for your class when scores are complete (Grades → *Generate report
cards*). The **principal** publishes them — after that they appear in the
parent portal and parents get an SMS.

## 4. Other tasks

- **Student info**: Students → tap a student. You can add guardians (their
  phone becomes their portal login), log discipline incidents, and take the
  student's photo with your phone camera.
- **Lesson plans**: stored under Academics → lesson plans (via API/admin UI).
- **Leave**: Staff → Leave requests → *Request leave*. You'll see
  approved/rejected there; if you're named substitute for someone you get an SMS.
- **Timetable**: 🗓 Timetable shows your class's week.
- **Library**: you can lend and receive books (Library → search → *Lend*).

## Tips for low battery / bad network

- Turn on 🌙 dark mode (Settings) — saves battery on most phones.
- Open your class list and roll call screen once while online; after that they
  work offline every day.
- The 📶 icon (top right) shows changes still waiting to upload. They go when
  any network returns — you never need to re-enter anything.
